# Inventario Restaurante

CRUD usando Java, Hibernate ORM y PostgreSQL

## Funciones

- Crear productos
- Listar productos
- Buscar producto por ID
- Actualizar productos
- Eliminar productos

## Base de datos

Crear una base de datos en PostgreSQL llamada:

inventario_restaurante

## Tecnologías

- Java
- Maven
- Hibernate
- PostgreSQL
- NetBeans

## Ejecución

1. Abrir el proyecto en NetBeans
2. Verificar que PostgreSQL esté encendido
3. Crear la base de datos inventario_restaurante
4. Revisar la contraseña en persistence.xml (contraseña: 1234)
5. Ejecutar el archivo principal InventarioRestaurante.java
